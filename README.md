# みまもりリマインダー

高齢のご家族が、決まった時間に「おくすりを飲む」などをやり忘れないようにするAndroidアプリです。

- 時間になると **アラームが鳴り、画面いっぱいにお知らせ** が出ます（アプリを閉じていても、画面が消えていても、ロック中でも）
- 内容を **日本語で読み上げ** ます（「8時30分です。あさのおくすりの時間です。」）
- 大きな **「完了」ボタン** を押すと記録されます
- 完了・未完了が **Googleスプレッドシート** にたまるので、離れて暮らすご家族が確認できます
- 文字は大きく、色はハッキリ。キャラクターや装飾はありません

> ⚠️ このアプリは飲み忘れを減らすための補助です。命にかかわるお薬の管理を、これだけに頼らないでください。

## 1. APKを作る

PCに何もインストールせず、GitHubのサーバーでAPKを作ります。**無料**です。

1. https://github.com で無料アカウントを作る
2. 右上の「＋」→ **New repository**
   - Repository name: `mimamori-reminder`（なんでもOK）
   - **Public**（公開）を選ぶ … Actions が無制限で無料になります
   - 「Create repository」
3. 次の画面の **uploading an existing file** をクリック
4. このフォルダの中身を **まるごとドラッグ＆ドロップ** する
   - `.github` フォルダも必ず含めてください（これがビルドの指示書です）
   - フォルダごとドラッグできない場合は、フォルダを開いて中身を全部選んでドロップしてください
5. 下の「Commit changes」を押す
6. 上の **Actions** タブを開く → 「APKをつくる」が自動で走り始めます（5〜10分）
7. 緑のチェック✅がついたら、その実行をクリック → ページ下の **Artifacts** にある
   `mimamori-reminder-apk` をダウンロード
8. ZIPを解凍すると **`app-debug.apk`** が入っています

以降、ファイルを直すたびに自動で新しいAPKが作られます。

> ❌ 赤い × が出たら、その実行をクリックして赤い行を開き、エラーメッセージをコピーして
> 私に貼り付けてください。直します。

## 2. スマホに入れる

1. `app-debug.apk` をスマホに送る（メール添付、Googleドライブ、USBなど何でも）
2. スマホでそのファイルをタップ
3. 「提供元不明のアプリ」「この提供元のアプリを許可」と出たら **許可** する
4. インストール → アプリ一覧に「みまもりリマインダー」が出ます

> このAPKはデバッグ用の署名です。個人で使う・家族に配る分には問題ありません。
> Google Play に出す場合だけ、別途リリース署名が必要になります。

## 3. 端末側の設定

**ここが一番大事です。** アプリを開いて「設定」タブを開くと、必要な項目が
✅ / ⚠️ で並んでいます。**すべて✅にしてください。**

| 項目 | なぜ必要か |
|---|---|
| 通知を出す | これがないと何も表示されません |
| 時間ちょうどに鳴らす | 省電力機能に邪魔されず、指定時刻に正確に鳴らすため |
| 画面いっぱいに出す | Android 14以降、これがないと小さな通知しか出ません |
| 電池の節約から外す | これがないと、しばらく使っていないと鳴らなくなります |
| 日本語の音声が使える | 読み上げに必要。無い場合は Google音声サービス を入れてください |

設定できたら、**「10秒後にテストする」ボタン** を押して、画面を消して待ってみてください。
画面が点いて、音が鳴って、読み上げが始まれば成功です。

### メーカー独自の省電力設定にも注意

Xperia / AQUOS / Galaxy / OPPO / Xiaomi などは、Android標準とは別に独自の省電力機能があります。
うまく鳴らない場合は、端末の設定から次を探して、このアプリを **対象外** にしてください。

- Xperia … 「STAMINAモード」「いたわり充電」→ アプリの電池使用量を最適化しない
- AQUOS … 「長エネスイッチ」→ 対象外アプリに追加
- Galaxy … 「バッテリー」→「使用していないアプリを一時停止」から除外
- Xiaomi / OPPO / vivo … 「自動起動」を許可 ＋「バッテリーセーバー」を制限なしに

## 4. Googleスプレッドシートとつなぐ

離れて暮らすご家族が、完了状況を見られるようにします。**無料** です。

1. Googleスプレッドシートを新規作成（https://sheets.new）
2. メニューの **拡張機能 → Apps Script**
3. エディタの中身を全部消して、このフォルダの `apps-script/Code.gs` の中身を貼り付ける
4. 保存（💾）してから、右上の **デプロイ → 新しいデプロイ**
   - 歯車⚙ → **ウェブアプリ** を選ぶ
   - 説明: なんでもOK
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員** ← ここを間違えると動きません
   - 「デプロイ」→ 権限の確認画面が出たら承認する
5. 表示された **ウェブアプリのURL** をコピー
   （`https://script.google.com/macros/s/……/exec` という形）
6. アプリの「設定」タブ → 「Apps Script のURL」に貼り付け → **接続テスト**
   - ✅ が出たら、スプレッドシートに「テスト」の行が増えているはずです

### ご家族の見かた

- **スプレッドシートを開く** … 「記録」シートに全部たまります
- **同じURLをブラウザで開く** … 今日を含む直近7日分が、見やすい一覧で表示されます
  （このURLをご家族のスマホでブックマークしておくのがおすすめです）

いつ送られるか:

- 「完了」を押した瞬間に1件
- 毎日 23:50 に、その日の全予定を「完了 / 未完了」でまとめて1回

圏外のときは端末に貯めておき、次につながったときにまとめて送ります。

## 5. 使いかた

**今日** タブ … 今日やることが時間順に並びます。終わったら大きな「完了」を押すだけ。

**よてい** タブ … 予定の追加・編集。「＋ 追加」から、

- なにをする？（例：あさの おくすり）
- じかん（＋ − ボタンで合わせる）
- ようび（毎日なら全部オン）
- 読み上げる言葉（空なら題名から自動で作ります。
  「青い袋のお薬を飲んでください」のように具体的に書くこともできます）

右のスイッチで、消さずに一時的に止められます。

**設定** タブ … 端末の設定、動作テスト、鳴らす長さ、スプレッドシート連携。

## 6. うまく鳴らないとき

| 症状 | 確認すること |
|---|---|
| まったく鳴らない | 設定タブが全部✅か／端末を再起動してから「10秒後にテスト」 |
| 音は鳴るが画面が出ない | 「画面いっぱいに出す」が✅か（Android 14以降は必須） |
| 数分遅れて鳴る | 「時間ちょうどに鳴らす」「電池の節約から外す」が✅か |
| しばらく使わないと鳴らない | メーカー独自の省電力設定（上の表）を確認 |
| 読み上げない | 「日本語の音声が使える」が✅か／音量が「アラーム」で0になっていないか |
| 再起動すると鳴らなくなる | 一度アプリを開いてください（開くと予約を貼り直します） |

## 7. 中身のしくみ

```
app/src/main/java/com/mimamori/reminder/
  Models.kt        タスクの形と、「次にいつ鳴るか」の計算（テスト対象）
  Repo.kt          保存（SharedPreferences ＋ JSON。データベースなし）
  Scheduler.kt     AlarmManager への予約／取り消し
  App.kt           通知チャンネルの作成、起動時の予約復元
  Receivers.kt     時間が来たとき・完了ボタン・再起動後の処理
  AlarmService.kt  アラーム音 → 読み上げ → 通知（短時間だけ動く前面サービス）
  AlarmActivity.kt 画面いっぱいのお知らせ画面（ロック中でも出る）
  MainActivity.kt  今日／よてい／設定 の3画面
  SheetSync.kt     スプレッドシートへの送信と再送キュー
  Speaker.kt       日本語の読み上げ
apps-script/Code.gs  スプレッドシート側（記録の保存＋家族向けの表示画面）
```

技術的なポイント:

- **`setAlarmClock()`** で予約しています。省電力状態（Doze）でも確実に起きる、いちばん強い方法です
- **フルスクリーンインテント** で `AlarmActivity` を開きます。これがアプリを閉じていても
  画面いっぱいに出る仕組みです（Android 14以降は `USE_FULL_SCREEN_INTENT` の許可が必要）
- 鳴っている間だけ **前面サービス** が動き、読み上げが終わると自分で止まります。
  未完了なら「まだ完了していません」通知だけを残します
- 保存はすべて SharedPreferences ＋ JSON。**依存ライブラリを最小限**にして、
  ビルドが壊れにくくしてあります
